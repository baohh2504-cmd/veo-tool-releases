# Veo Batch Studio — bản cài đặt

Repo này chỉ chứa file cài đặt của Veo Batch Studio (Windows).

## Cài đặt
1. Vào mục **Releases** bên phải, tải file `VeoBatchStudio-Setup-<phiên bản>.exe` của bản mới nhất.
2. Mở file để cài. Windows có thể cảnh báo vì app chưa có chữ ký số: bấm **More info → Run anyway**.

## Cập nhật
Mở app là app tự kiểm tra bản mới. Khi thấy thanh **"Có bản mới – Cập nhật"**, bấm để tải rồi bấm **"Khởi động lại để cập nhật"**. Dữ liệu (acc, dự án, cài đặt) được giữ nguyên.
